Source and model

The named history input is a complete snapshot of saas_subscription_kpis. The baseline is its latest month_end and mrr_usd. Forecast MRR = baseline × (1 + monthly growth / 100)month. Annualized run rate = MRR × 12; it is not recognized annual revenue.

This uses the existing SaaS view's monthly subscription and classification conventions. It does not model acquisition, churn and expansion separately. Data does not refresh on opening; use Studio's Data inputs panel. Refreshing inputs preserves assumptions and previous results. Changed data marks results outdated; an identical snapshot leaves them current. Run a scenario to replace its previous result, then Save document to retain it. Reopening restores the saved snapshot and results without rerunning.
