# Development priorities

This is a direction for discussion, not a release commitment.

1. Clear Saving / Saved / Failed feedback and reliable recovery of editor drafts.
2. Portable project backup/export and recoverable deletion.
3. More teaching examples for paths, missing values, joins, and messy data.
4. Accessible keyboard navigation and clearer empty/error states.
5. Cross-platform setup and broader automated browser/kernel coverage.
6. Dependency review and locally bundled frontend assets for offline use.
7. Validate Intel and Windows desktop builds; bundle frontend assets for offline use.

The first Apple Silicon desktop preview is available. App Store distribution and notarization are not planned for this preview.
