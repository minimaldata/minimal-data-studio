Minimal Data Studio — early preview for macOS 12 or later

1. Download the Apple Silicon ZIP for an M-series Mac.
   This first preview does not include an Intel build.
   Check Apple menu > About This Mac if unsure.
2. Unzip it and move Minimal Data Studio.app to Applications.
3. Double-click the app. Choose an empty folder for a new project, or a previous
   Studio project folder. The app opens Studio in your default browser.
4. Keep the app running while you work. Use its window to reopen the browser
   or choose another project. Quit the app to stop its local server.

This preview is not notarized or distributed through the App Store.
macOS may block the first launch. After attempting to open the app, you can
review it in System Settings > Privacy & Security and choose Open Anyway.
Only do this for the download you obtained from the official repository.
See Apple's guidance: https://support.apple.com/en-us/102445

SQL and Python, including pandas, PyArrow and matplotlib, are included.
You do not need to install Python or start a server yourself.
R is optional and installed separately. Help > Runtime setup explains it.

An internet connection is required to load frontend libraries.
This is an early preview, not a signed production release.
Windows is not included in this download.

Your project folder holds your files, .studio/workspace.duckdb, saved queries,
and backups. Your work is outside the application, so replacing the app does
not replace it. Back up the complete project folder after quitting Studio.

The code you run and the terminal have your normal local account permissions.
Only open code and projects you trust.

Source and releases: https://github.com/minimaldata/minimal-data-studio

REOPENING AND UPDATING
Double-click Open Project.mdsproject inside your project folder to return to it.
Keep this file with the whole project folder; it does not contain the data itself.
To find the folder from Studio, click the project location, then Open in Finder.
Use Help > Check for updates for new downloads. Save your work, quit Studio,
and replace the app in Applications. Keep your existing project folder.
Download guide: https://minimaldata.github.io/minimal-data-studio/
