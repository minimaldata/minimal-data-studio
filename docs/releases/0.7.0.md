# Minimal Data Studio 0.7.0

Stable release · build 16.

## Changes since 0.6.0

- Project workspaces open in native Mac windows, with an option to open in a browser. Native menus provide project actions, appearance, and a save-before-reload command.
- A floating calculator captures table and chart selections, supports aggregation and editable expressions, and saves its scratchpad with the project. A compact result-footer readout copies statistics directly.
- Table selection supports disjoint cells, whole rows and columns, ranges, and row/column intersections. Copy formatting can produce Standard or SQL values, with optional column names and distinct SQL tuples. Copies preserve numeric precision and identify loaded-preview scope.
- Column inspection adds missing-value, distinct-value, numeric distribution, and date summaries.
- Charts gain categorical scatter layouts, beeswarm, box-and-whisker and violin overlays, consistent automatic legends, horizontal scrolling, and trackpad navigation. Multi-measure selection applies changes together.
- Connection setup uses guided steps with review, missing-field feedback, and connection testing before saving. Direct Postgres setup supports SSH tunnels, private-key selection, and Keychain-backed passphrases.
- PNG export now works in native windows and for static bar/line charts; export failures are shown instead of silently ignored.
- Editor line movement, explorer actions, tabs, menus, and chart layout have usability fixes.

## Distribution status

Version 0.7.0 replaces 0.6.0 as the recommended student download. Project files remain outside the app and are preserved when updating.
Distribution requires Developer ID signing, Apple acceptance and stapling for both
the app and installer, and Gatekeeper verification. The release validation record
tracks those checks separately from the automated and native interaction tests.

Release source companions: R 4.6.2, nanoparquet 0.5.2, psycopg 3.3.9, and Paramiko
3.5.1. Each component keeps its upstream license.
