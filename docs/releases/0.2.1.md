# Minimal Data Studio 0.2.1

- New black app icon with a larger white Minimal Data mark.
- Cleaner drag-to-Applications installer with clear instructions and background artwork kept outside the visible area.
- Imported tables and other objects without a saved SQL definition now open as data previews. The definition editor cannot replace them or change their materialization. To transform them, use a separate query and create a new table.

Update from 0.2.0 using Help → Check for updates or the Minimal Data Studio menu. Save unsaved code and finish running queries before choosing Install and restart. Your project files remain in their existing folder.

Apple Silicon · macOS 14 or newer · SQL, Python and R included.
