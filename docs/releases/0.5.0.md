# Minimal Data Studio 0.5.0

- Explore scatterplots with size, shape, color and brightness mappings, category styling, and pan and box zoom. Large datasets use a Canvas overview with detailed interaction when zoomed in.
- Explore line charts with compact series and cohort strips, grouped selection, configurable colors and tooltips, and time-axis controls down to milliseconds. Stacked bars and percent-of-total charts show the combined contribution of selected series.
- Resize notebook code and output areas independently. Sizes persist per cell; double-click a resize handle to reset.
- Manage crowded workspaces with preview tabs, searchable open tabs and bulk closing. Rename analyses and folders in place. Opening a saved query edits the original, and saving retains its chart settings. Duplicate saved-query names are prevented.
- Add external connections through one source chooser, including a dedicated Supabase setup flow. Connector instructions explain authentication and TLS, with a file picker for public CA certificates.
- Fix chart hover cleanup and task cancellation bookkeeping.

Apple Silicon Mac; macOS 14 or newer. Python and R included. Internet is required for frontend libraries and remote databases.

## Notes

Remote access requires your own database permissions and authentication. Snowflake, Postgres and Supabase access is read-only. Warehouse queries can incur provider charges.

Credentials stay on this Mac, outside project folders. Credentials held by separately identified preview apps are not copied into the release. Imported CA certificates also stay on this Mac.

Install the DMG by dragging Studio to Applications, or use Check for Updates in the app. Back up your project folder before upgrading; project files stay outside the app.
