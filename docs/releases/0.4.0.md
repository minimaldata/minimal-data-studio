# Minimal Data Studio 0.4.0

- Connect to BigQuery, Snowflake and Postgres alongside local DuckDB and project files. Browse remote sources, choose a connection per SQL editor or notebook cell, and bring complete results into local analyses.
- Save full remote output as CSV, a DuckDB table, or both with separate names. Transfers stream to disk with an adjustable budget, progress and cancellation. Saving both downloads the result once. The grid remains a 1,000-row preview.
- Create BigQuery model drafts, publish tables or views, track SQL versions, and reference managed models with `{{ }}`. Inspect dependencies and compiled SQL before publishing.
- Select Google authentication profiles per BigQuery connection. Reuse Snowflake sessions and cache MFA approval in macOS Keychain when permitted by the account.
- Improve connection status, authentication guidance and loading animations, and fix editor scrolling and cursor presentation.

Apple Silicon Mac; macOS 14 or newer. Python and R included. Internet is required for frontend libraries and remote databases.

## Notes

Remote access requires your own database permissions and authentication. Snowflake and Postgres access is read-only. Warehouse queries can incur provider charges; transfer budgets do not limit warehouse bytes scanned.

BigQuery and Snowflake full transfers read the original query result. Postgres asks before rerunning a SELECT when the complete result is no longer retained. Notebook inputs still require complete results within their separate 100,000-row / 64 MB limit.

Credentials stay on this Mac, outside project folders. Credentials held by separately identified local preview apps are not copied into the release. Configure them in the released app if needed. Google Cloud CLI installation is separate when signing in to a Google profile.

Install the DMG by dragging Studio to Applications, or use Check for Updates in the app. Back up your project folder before upgrading; project files stay outside the app.
