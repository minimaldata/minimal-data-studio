# Minimal Data Studio 0.2.2

- Manage running and recent projects from the Mac app, with New project, Open, Finder, and Stop controls.
- See database size, table/view counts, and clickable local addresses.
- Reuse one server per project and detect conflicting saves from other browser tabs.
- Automatically check SQL, Python, and R when opening a project. Expand the status summary for results and troubleshooting.
- Choose managed or custom Python and R installations per project in Advanced settings.
- Fix a preview server failure when sending notebook input tables to Python or R.
- Refine the project manager layout, action buttons, cursor feedback, and app icon loading.

Includes Python and R. Apple Silicon; macOS 14 or newer.
