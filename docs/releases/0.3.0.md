# Minimal Data Studio 0.3.0

- Add editable assumption cells: independent Values over time and stacked % of total charts, with named series, fixed historical data, future points, date ranges, yearly intervals, axis/snap controls and monotonicity for value charts. SQL, Python and R can consume their outputs.
- Add Python Tasks with an in-app script editor, run/stop controls, logs, explicit credential access and schedules while Studio is running. Schedules show the next run, support pause/resume and report missed runs without overlapping executions.
- Add a searchable macOS Keychain credentials manager, project connections and authentication to reveal a secret.
- Open notebooks and dashboards as persistent tabs. Protect saved work when the same project is open in multiple browser tabs.
- Improve project-backed editor drafts, frontend organization and automated browser checks.

Apple Silicon Mac; macOS 14 or newer. Python and R included. Internet is required for frontend libraries and remote data sources.

## Notes

Task schedules run only while Studio and the project are running. Credentials from separately identified local preview apps are not copied into the release; reconnect credentials in the release app if needed.

Older experimental Normal assumption cells now open as separate value and standard-deviation series. New assumption outputs contain series, date, value and segment; downstream code using the former mean/sd columns needs updating.

Install the DMG by dragging Studio to Applications, or use Check for Updates in an existing release. Project folders stay outside the app. Back up your project folder before upgrading.
