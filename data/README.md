# Iris sample data

Source: R. A. Fisher (1936), *Iris*, UCI Machine Learning Repository.
Dataset: https://archive.ics.uci.edu/dataset/53/iris
DOI: https://doi.org/10.24432/C56C76
Download: https://archive.ics.uci.edu/static/public/53/iris.zip
License: Creative Commons Attribution 4.0 International (CC BY 4.0),
https://creativecommons.org/licenses/by/4.0/

Retrieved 2026-11-07. This CSV uses `bezdekIris.data` from the archive,
with a header added and trailing blank lines removed. Numeric values and
species labels are unchanged. Four measurements are in centimetres; each
row describes one flower. There are 150 rows, 50 in each of three species.
No endorsement by the original author or repository is implied.
