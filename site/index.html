Install

  1. Open the download

    Download the DMG above. In Downloads, double-click it to see Minimal Data Studio.app.

  2. Drag to Applications

    Drag the app onto the Applications shortcut, eject the disk image, then open Minimal Data Studio from Applications.

  3. Choose a project folder

    Create an empty folder for a new project, or choose your existing Studio project. Studio opens in your default browser. Keep the app running while you work.

Need help? Email christian@minimaldata.com or report an issue on GitHub.
