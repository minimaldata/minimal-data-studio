Release notes & checksum

Signed with Developer ID and notarized by Apple. This is still an early preview, distributed through GitHub. Your Mac may show the normal confirmation that the app was downloaded from the internet.

Start in three steps

  1. Download & unzip

    Download the ZIP above. In Downloads, double-click it to extract Minimal Data Studio.app.

  2. Move & open

    Drag the app to Applications, then double-click it. If macOS blocks it, follow “My Mac won’t open the app” below.

  3. Choose a project folder

    Create an empty folder for a new project, or choose your existing Studio project. Studio opens in your default browser. Keep the app running while you work.

Coming back tomorrow?

Open your project folder and double-click Open Project.mdsproject. Studio starts and brings your workspace back up. You don’t need to remember a localhost address.

Or open the app again to return to the last project. In Studio, click the project location and Open in Finder to find your files.

A little help getting settled

Which Mac download do I need?

Choose Apple menu → About This Mac. If “Chip” shows Apple M1, M2, M3, M4, or another M-series chip, use this download. Intel Macs and Windows computers need a different build, which is not available yet. The bundled R release requires macOS 14 or later; testing so far has focused on macOS 26.5.2.

The download didn’t finish, or the ZIP won’t open

Wait for your browser to finish downloading, then open the ZIP from Downloads. If it is incomplete, download it again from this page. Try the GitHub release page if the button fails. A school network may block GitHub downloads; ask your instructor or IT team.

My Mac won’t open the app

The current download is signed and notarized. If Apple says it cannot verify the app, you may have an older copy: quit Studio, download the ZIP again from this page, and replace the app in Applications. Keep your project folder. Apple explains macOS launch messages here.

If your school manages the Mac, installation may still require IT approval. If macOS says the app contains malware, or is damaged, don’t disable security protections. Download a fresh copy from the release page and report the exact message if it persists.

The browser says it can’t connect to localhost

The Studio app needs to be running. Open it and click Open in browser, or double-click your project’s .mdsproject file. An old browser bookmark may point to a previous port. Use the app to get the current address.

My .mdsproject file opens as text, or won’t open

Install version alpha.2 or newer in Applications and open the app once. In Finder, Control-click the project file, choose Open With → Minimal Data Studio (or Other… to locate it). You can also open the app and choose the enclosing project folder directly. Older projects get this file when opened with the updated app.

Keep the file inside the project folder. It identifies the folder; it does not contain your tables or saved work.

The page is blank or keeps loading

The interface currently downloads some libraries from the internet. Check your connection, then reload. A school firewall or browser extension may block these resources. Share the error with your instructor; offline support is not included in this preview.

Where is my work? How do I back it up?

Check that you opened the right project folder. Your source files, saved work, and database stay there, outside the application. In Studio, click the project location, then Open in Finder. Save your queries and quit Studio before copying the whole project folder, including hidden files, for backup. Copying only the .mdsproject file does not copy your work.

Unsaved editor tabs and some interface preferences are browser-local and may not carry over between launch addresses. Save queries before quitting.

Python or R won’t run

Open Help → Runtime setup and check the selected runtime and packages. Python and its teaching packages are included in the Studio-managed environment. R 4.6.2, its recommended packages and nanoparquet are included in alpha.3. Choose Studio-managed to use them. Tidyverse and optional X11/Tcl interfaces are not included; base plots use Quartz. If you chose your own Python installation, switch back to Studio-managed or check its packages.

The project won’t start, or the database is locked

Use a writable project folder. If another copy of Studio or a development server has that project open, close it before trying again. Don’t delete database files to fix a lock. If startup still fails, copy the error message and report it.

Keep Studio up to date

New in alpha.3: R is bundled alongside Python and SQL. All three languages work without a separate runtime installation. You can still choose your own Python or R installation in Help. Requires macOS 14 or newer.

  1. Save your work and quit Studio.
  2. Download the current version and unzip it.
  3. Replace the app in Applications.
  4. Open your existing project again.

This page stays on the approved student release while future changes are tested in previews. Your project folder stays where it is. Updates are manual; the Help link opens this page and does not install anything.

Still stuck?

Report a problem on GitHub or ask your instructor. Include the Studio version, your macOS version and chip, what you tried, and the exact error. Leave private data and personal file paths out of public reports.
