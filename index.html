    Help & reference
    
    
    Start with the error message, then narrow the problem to one statement or a few rows. Change one thing at a time.
    SQL
    Common syntax
    SQL reads database tables. These examples use the bundled iris table; replace its names with your own.
    -- Choose columns and filter rows
SELECT species, sepal_length
FROM iris
WHERE sepal_length >= 5
ORDER BY sepal_length DESC
LIMIT 100;

-- Summarize each group
SELECT species, AVG(sepal_length) AS mean_length
FROM iris
GROUP BY species;

-- Missing values
SELECT * FROM iris
WHERE species IS NULL;
    Use single quotes for text, such as 'Iris-setosa'. Double quotes identify columns or tables with spaces. Use IS NULL rather than = NULL.
    Understanding common errors
    Read the error category first, then the name or location mentioned in the message.
    Parser Error: syntax near …
    DuckDB could not understand the statement. The marked location is where parsing stopped, not always where the mistake began.
    Check the preceding comma, quote, parenthesis, and clause order: SELECT → FROM → WHERE → GROUP BY → HAVING → ORDER BY → LIMIT. Run one statement at a time.
    Catalog Error: table does not exist
    The table or view name could not be found. A file in Files is not automatically a database table.
    Look under Database for the exact name. Import the file if needed. A notebook temporary table is only available in its current database session.
    Binder Error: column or grouping problem
    SQL could not resolve a column, or a selected column conflicts with grouping.
    Expand the table to check column names. In a join, qualify shared names with table aliases. With GROUP BY, group each selected column that is not inside an aggregate.
    Conversion Error: a value cannot be converted
    A text value does not match the number or date type requested.
    Inspect the original values first. TRY_CAST can help locate failures, but it returns NULL for invalid values—do not silently treat those as valid missing data.
    SELECT value
FROM your_table
WHERE value IS NOT NULL
  AND TRY_CAST(value AS DOUBLE) IS NULL;
    IO Error / CSV parsing error
    The file could not be read, or its rows do not match the expected format.
    Check the project-relative path and use the file Source view to inspect delimiters, quotes, and inconsistent rows. Confirm the import format before changing or skipping data.
    Python
    Common syntax
    Python uses pandas DataFrames. In this app pandas is available as pd. Referenced database tables with simple names are provided as DataFrames.
    # Inspect rows and column names
iris.head(10)
list(iris.columns)

# Filter and select columns
iris.loc[iris["sepal_length"] >= 5,
         ["species", "sepal_length"]]

# Summarize
iris.groupby("species", as_index=False)["sepal_length"].mean()

# Read a project file directly
df = pd.read_csv("data/iris.csv")
df.head(10)
    End the run with a DataFrame expression to show a table. Each main-editor run starts a fresh process: include the assignments and imports it needs in that run.
    Understanding common errors
    NameError: name is not defined
    Python does not have a variable with that exact name in this run.
    Check spelling and capitalization. Include the assignment or import above its use and run both together. A variable created in a previous main-editor run is not retained.
    KeyError: column name
    The requested column or key was not found.
    Inspect list(df.columns). Watch for spaces, capitalization, and a CSV header parsed with the wrong delimiter. Use df["column name"] for names with spaces.
    SyntaxError / IndentationError
    Python cannot parse the code or its indentation.
    Check quotes, parentheses, colons after if/for/def, and consistent indentation. The highlighted line may follow the actual mistake.
    TypeError / ValueError
    An operation received the wrong kind of value or an invalid value.
    Inspect df.dtypes and a few source values. Text that looks numeric may contain commas or spaces. Investigate failed conversions before coercing them to missing values.
    FileNotFoundError
    The path does not point to an existing file from the project working directory.
    Use Files → Details → Copy relative path, then put the path inside quotes. Bring files from outside the project into Files first.
    ModuleNotFoundError
    The Python environment running this app does not have the requested package.
    Check the package name. Ask your instructor to install it into the app’s Python environment; installing into a different Python environment will not fix this run.
    R
    Common syntax
    R works with data.frames. Referenced database tables with simple names are made available by name. These examples use base R.
    # Inspect
head(iris, 10)
names(iris)
str(iris)

# Filter and choose columns
iris[iris$sepal_length >= 5,
     c("species", "sepal_length")]

# Summarize
aggregate(sepal_length ~ species,
          data = iris, FUN = mean)

# Read a project file directly
df <- read.csv("data/iris.csv")
head(df, 10)
    End the run with a data.frame expression to show a table. Each main-editor run starts fresh. Include the assignments and library() calls it needs.
    Understanding common errors
    object not found
    R cannot find the object or column named in the error.
    Check names(df) and exact capitalization. Use df$column or df[["column"]] where appropriate. Run the assignment and the code that uses it together.
    could not find function / no package called …
    A function is unavailable, often because its package is not loaded or installed.
    Check the function’s spelling and library(package). If the package is missing, ask your instructor to add it to the R installation used by this app.
    unexpected symbol / unexpected end of input
    R could not finish parsing the expression.
    Check unmatched quotes, parentheses, braces, and missing commas. Start with the line immediately before the reported location.
    non-numeric argument / NAs introduced by coercion
    A calculation encountered text, or conversion produced missing values.
    Use str(df) and inspect the affected values. A coercion warning means some values became NA; investigate those rows before calculating summaries.
    cannot open connection
    R could not open the requested file or resource.
    Read the rest of the message. For a local file, copy its project-relative path from Details and check that it exists. Use forward slashes in quoted paths.
    Minimal Data Studio
    App basics
    Files and database tables are separate. Bring files copies source files into the project. Opening a file previews it without importing or editing it. Import as table creates a separate snapshot in DuckDB.
    File tabs have a document icon and File label. Editor tabs have a SQL/Python/R selector and run code. Open table creates a SQL query for a linked table; it does not edit the file.
    All code starts from the project folder. data/iris.csv means: enter data inside the project, then read iris.csv. Details shows both the full path from the filesystem root and the project-relative path.
    Permanent tables and views survive reload in the local DuckDB database. Saved queries use Save; notebooks and dashboards save automatically. Editor drafts are stored in this browser. File preview tabs currently last for the page session.
    Run executes selected code, or the current SQL statement when nothing is selected. Run all runs the whole editor tab. Create table saves a result snapshot; Create view saves the SQL definition and reads current data when queried.
    Understanding common errors
    Could not connect / failed to fetch
    The browser could not reach the local app server.
    Check that the local server is still running. Preserve any unsaved code before reloading. Restarting the server does not delete permanent tables or project files.
    Outside this project / file not found
    The file browser cannot access that path within this project.
    Use Bring files to copy the file into the project, then use its relative path. If a file was moved outside the app, refresh Files and check its new location.
    R is not installed / kernel cannot start
    The code runtime is missing or cannot be launched.
    Ask your instructor to check the local R or Python setup. Choosing a language in the tab does not install its runtime.
    Saved work changed in another tab
    Another browser tab or window saved a newer version of the shared workspace.
    Copy any work you need to keep before choosing Reload the latest. Keep this tab’s version overwrites the newer version; use it only after deciding which version to keep.
    Preview parsing error / limited preview
    The viewer could not parse the file, or is showing only the beginning.
    Use Source to inspect CSV/TSV/JSON text. Table previews stop at 100 rows and text at 1 MB. The preview is not evidence that later rows are clean. Import and query to explore the complete dataset.
    Stopped after 10 minutes
    The local run exceeded its execution time limit.
    Try a smaller input or simpler operation. Check joins for an unexpectedly large result and Python/R loops for a stopping condition.
    No results / results look out of date
    This may be a query or workflow issue rather than a software error.
    Run the relevant editor tab again. Check filters and NULL values. A file and its imported table are separate snapshots; changing one does not update the other. Notebook cells may need to run again from the top.
